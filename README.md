## 📋 Project Overview

BuildLLM acts as a learning space for anyone interested in how language models work. This application takes you through the steps to build three different types of language models. You learn the mechanics of machine learning, transformers, and tokenizers by doing the work yourself. 

The software provides a guided path. You move from basic concepts to building complex systems. You gain skills in deep learning without needing a computer science degree. The lessons focus on transparency and logic. Each stage builds on the one before it to ensure you understand the full process.

## ⚙️ System Requirements

Your computer needs specific hardware to run these models effectively. Ensure your system meets these standards:

- Operating System: Windows 10 or Windows 11.
- Processor: An Intel Core i5 or AMD Ryzen 5 or better.
- Memory: At least 16 gigabytes of RAM.
- Graphics Processing Unit: An NVIDIA graphics card with at least 8 gigabytes of video memory. This component is necessary for training models.
- Storage: 10 gigabytes of free space on a solid-state drive.
- Software: Python version 3.10 installed on your machine.

## 🚀 How to Install and Run

Follow these steps to set up the software on your Windows computer.

3. Click "Download ZIP" to save the project folder to your computer.
4. Extract the contents of the ZIP folder to a location on your hard drive.
5. Open your Command Prompt or PowerShell and navigate to the folder where you saved the files.
6. Type the command `pip install -r requirements.txt` to install the necessary tools.
7. Run the startup script by typing `python main.py` into your terminal window.

The application starts in your browser. You can now follow the guided labs on your screen.

## 📚 What You Will Learn

This project breaks down complex topics into small, manageable parts. You gain knowledge in these specific areas:

### Tokenization
You start by learning how computers read text. Tokenizers turn words into numbers that machines understand. You build a system that breaks down sentences into individual components.

### Transformer Architecture
You learn the structure of the modern systems powering AI today. You study how attention mechanisms allow models to focus on important parts of a sentence. You see how data flows through a neural network.

### Model Training
You move to the physical training of three generations of models. Each generation improves upon the last. You observe how the model learns patterns and structures from data. You see how it generates text based on what it learned.

## 🛠 Troubleshooting

If you encounter issues during setup, try these steps:

- Check your Python path: Ensure Python appears in your Windows environmental variables.
- Update your graphics drivers: Visit the NVIDIA website to install the latest drivers for your graphics card.
- Re-run the requirement installation: Sometimes a slow internet connection causes the installation command to fail. Run the command again to ensure all tools exist on your system.
- Inspect the logs: The terminal window shows text while the program runs. If an error occurs, the window displays a message explaining the problem.
